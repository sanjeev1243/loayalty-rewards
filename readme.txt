== Description ==

NetScore Loyalty Rewards for WooCommerce enables merchants to create a customer loyalty program by rewarding customers with points for purchases. Customers can redeem earned points during checkout, encouraging repeat purchases and improving customer retention.

The plugin integrates seamlessly with WooCommerce and supports optional NetSuite synchronization for businesses using NetSuite ERP.

== Features ==

* Earn loyalty points for WooCommerce purchases.
* Redeem loyalty points during checkout.
* Configurable earning and redemption rules.
* Reward transaction history.
* Customer reward balance.
* WooCommerce My Account integration.
* Admin dashboard for loyalty settings under WooCommerce menu.
* NetSuite ERP omnichannel sync support.
* Translation ready.
* Developer-friendly architecture.

== Requirements ==

* WordPress 6.7 or higher
* WooCommerce 9.0 or higher
* PHP 7.4 or higher
* MySQL 5.7+ or MariaDB equivalent

== Installation ==

1. Upload the plugin ZIP file via **Plugins > Add New > Upload Plugin**.
2. Activate the plugin.
3. Ensure WooCommerce is installed and activated.
4. Navigate to **WooCommerce > Loyalty Rewards**.
5. Configure your loyalty program settings.
6. Save the configuration.

== Configuration ==

The plugin allows administrators to configure:

* Enable or disable the loyalty program.
* Points earning rules (signup, review, referral, birthday, anniversary).
* Point redemption value & threshold equivalent.
* Minimum order amount & redemption limits.
* Customer eligibility & loyalty tiers.
* NetSuite ERP integration settings.

== Customer Features ==

Customers can:

* Earn points after eligible purchases.
* View available reward points.
* Redeem points during checkout.
* View loyalty transaction history.
* Track reward balances from My Account.

== NetSuite Integration ==

The plugin supports optional NetSuite integration for synchronizing loyalty points, tiered pricing, and gift card records between WooCommerce and NetSuite ERP.

== Security ==

The plugin follows WordPress coding standards and includes:

* Input sanitization.
* Output escaping.
* Nonce verification.
* Capability checks (`manage_woocommerce`).
* Prepared database queries.
